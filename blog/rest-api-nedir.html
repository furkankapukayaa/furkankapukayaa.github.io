REST API Nedir?

Furkan Kapukaya · 6 min read

REST is an architectural style for designing networked applications around resources and standard HTTP semantics. A REST-style API should make its URLs, methods and responses predictable.

Resource yaklaşımı

Instead of naming URLs after actions, model the resources your application exposes. For example, /products can represent a collection of products.

HTTP metodları

  • GET reads data
  • POST creates a resource
  • PUT/PATCH updates a resource
  • DELETE removes a resource

Status kodları

Use status codes consistently: 200 for successful reads, 201 for creation, 204 when a successful response has no body, 400 for invalid input and 404 when a resource cannot be found.

İyi API tasarımı

Consistent naming, validation, authentication, error contracts and versioning become increasingly important as an API is consumed by more clients.
