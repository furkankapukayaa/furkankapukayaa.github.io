Entity Framework Core Nedir?

Furkan Kapukaya · 7 min read

Entity Framework Core is an object-relational mapper for .NET. It lets developers work with database records through C# objects while still providing control over queries and database design.

DbContext

DbContext represents a session with the database and exposes DbSet properties for entities. It also tracks changes that will be persisted.

Migrations

Migrations help version database schema changes alongside application code. They are useful when a project evolves through multiple releases.

LINQ ile sorgular

EF Core translates LINQ expressions into SQL where possible. This allows readable queries while keeping the database as the source of filtering and aggregation.

var activeUsers = await db.Users
    .Where(x => x.IsActive)
    .ToListAsync();

Performans

Use projection when you only need selected columns, avoid unnecessary loading and inspect generated SQL when a query behaves unexpectedly.
