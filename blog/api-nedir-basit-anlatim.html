API Nedir? Teknik Olmayanlar İçin Basit Anlatım

API kavramının restoran garsonu benzetmesiyle sade anlatımı, gündelik hayattaki API örnekleri, API anahtarı, entegrasyon maliyeti ve işletmelerin API sorarken dikkat etmesi gerekenler.

"Bu programın API'si var mı?" sorusu, artık sadece yazılımcıların değil işletme sahiplerinin de sorduğu bir soru. Çünkü API, iki yazılımın insan eli değmeden konuşabilmesi demektir; bu da zaman, hata ve maliyet tasarrufu anlamına gelir.

Garson benzetmesi

Bir restoranda mutfağa kendiniz girip yemek yapmazsınız. Menüden seçim yapar, siparişi garsona verirsiniz; garson mutfağa iletir ve yemeği size getirir.

  • Menü: API'nin sunduğu işlemlerin listesi (dokümantasyon)
  • Garson: API'nin kendisi
  • Mutfak: Karşı tarafın sistemi ve veritabanı

Mutfağın içinin nasıl işlediğini bilmenize gerek yoktur. Menüde ne varsa, kurallara uygun sipariş verirseniz alırsınız.

Gündelik hayattaki API örnekleri

  • Web sitenizdeki ödeme formunun bankaya bağlanması
  • Kargo firmasının takip numarasını otomatik olarak siparişe yazması
  • Muhasebe programının e-faturayı entegratöre göndermesi
  • Hava durumu uygulamasının verileri bir meteoroloji servisinden çekmesi
  • Randevu alındığında müşteriye otomatik SMS gitmesi

Bu örneklerin hepsinde iki sistem, bir API sözleşmesi üzerinden konuşur. Bkz. kargo entegrasyonu ve e-fatura entegrasyonu.

API anahtarı nedir?

Garsonun herkese değil, yalnızca masaya oturan müşteriye hizmet etmesi gibi API'ler de kimin istek yaptığını bilmek ister. API anahtarı, sistemin sizi tanıması için verilen gizli bir koddur. Bu anahtar bir şifre gibi korunmalı; e-postayla paylaşılmamalı, web sitesinin herkese açık kodlarına yazılmamalıdır.

API var mı yok mu: neden önemli?

Bir yazılım satın alırken API desteğini sormak, ileride yaşanacak pek çok sorunu önler:

  1. Veri sizin mi? API ile verinizi istediğiniz zaman dışarı alabilirsiniz.
  2. Bağlanabilir mi? Muhasebe, e-ticaret ve CRM gibi sistemler birbirine bağlanabilir.
  3. Otomasyon yapılabilir mi? Elle yapılan aktarım işleri ortadan kalkar.

API'si olmayan bir yazılımda verileri aktarmak için çoğu zaman Excel dışa aktarma veya ekran otomasyonu (RPA) gibi daha kırılgan yollara başvurmak gerekir.

Entegrasyon maliyetini ne belirler?

  • API'nin dokümantasyonunun kalitesi
  • Test ortamı (sandbox) sunulup sunulmadığı
  • Veri alanlarının iki sistem arasında ne kadar örtüştüğü
  • Hata durumlarında ne yapılacağı (tekrar deneme, bildirim)

Sık sorulan sorular

API ücretli midir?

Bazı hizmetler API'yi ücretsiz sunar, bazıları istek sayısına veya pakete göre ücretlendirir. Sözleşme öncesinde limitleri ve fiyatlandırmayı mutlaka sorun.

Webhook ile API aynı şey mi?

Hayır. API'de siz sorarsınız; webhook yönteminde ise karşı sistem bir olay olduğunda size haber verir.

Sonuç

API, yazılımlar arasındaki ortak dildir. Kullandığınız ve satın alacağınız sistemlerde API desteğini sormak, işletmenizin gelecekte büyürken esnek kalmasını sağlar. Mevcut sistemlerinizi birbirine bağlamak için iletişime geçebilirsiniz.
