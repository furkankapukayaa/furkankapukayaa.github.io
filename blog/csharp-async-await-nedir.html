C# Async/Await Nedir?

Furkan Kapukaya · 6 min read

Asynchronous programming helps an application continue useful work while it is waiting for an operation such as a database query, HTTP request or file operation. In C#, the Task, async and await model is the standard way to express this flow.

Task nedir?

A Task represents an operation that may finish in the future. A method can return Task when it performs asynchronous work, or Task<T> when it eventually produces a value.

async ve await ne yapar?

The async keyword marks a method that can use await. The await keyword lets the method yield while the awaited operation is incomplete, then continue when the result is ready.

public async Task<string> GetDataAsync()
{
    var response = await httpClient.GetStringAsync(url);
    return response;
}

Nerede kullanılır?

  • Database operations
  • HTTP/API requests
  • File operations
  • Other I/O-bound workloads

Async code is especially useful in web applications because threads do not need to sit idle while waiting for I/O.

Dikkat edilmesi gerekenler

Async does not automatically make CPU-heavy work faster. Avoid blocking asynchronous code with .Result or .Wait() when an asynchronous flow is available.
