Copy Unlocker Gizlilik Politikası

Son güncelleme: 15 Ağustos 2026

1. Genel Bakış

Copy Unlocker, web sayfalarında JavaScript veya CSS ile devre dışı bırakılmış metin seçimi, kopyalama, sağ tıklama ve sürükleme davranışlarını kullanıcının seçimiyle yeniden etkinleştiren bir Chrome uzantısıdır.

2. Toplanan Veriler

Uzantı ad, e-posta, şifre, finansal bilgi, sağlık bilgisi, konum veya kişisel iletişim gibi kimliği doğrudan belirleyen verileri toplamaz. Uzantı ayrıca web sitesi içeriğini veya kullanıcı etkinliğini sunucuya göndermez.

3. Yerel Ayarlar

Uzantı, kullanıcının açıkça seçtiği "Bu web sitesi" ve "Bu sayfa" tercihlerini cihazdaki Chrome uzantı depolamasında saklayabilir. Bu tercihler, ilgili site veya sayfada kullanıcının daha önce yaptığı seçimi hatırlamak için kullanılır. Bu nedenle kayıtlı site/sayfa tercihleri web geçmişiyle ilişkili yerel veriler olarak değerlendirilebilir; hiçbir sunucuya gönderilmez ve üçüncü taraflarla paylaşılmaz.

4. Sayfa İçeriği

Uzantı etkin olduğunda aktif HTTP/HTTPS sayfasında yerel olarak CSS ve JavaScript olaylarını değiştirebilir. Sayfa içeriği uzantı geliştiricisine gönderilmez.

5. İzinlerin Kullanımı

storage: Kullanıcının özellik, web sitesi ve sayfa tercihlerini cihazda kalıcı olarak saklamak için.

scripting: Kopyalama, metin seçimi, sağ tıklama ve sürükleme davranışlarını kullanıcının seçimiyle etkinleştirmek için.

commands: Alt + C / macOS Command + Shift + C klavye kısayolunu sağlamak için.

HTTP/HTTPS host permissions: “Bu web sitesi” özelliğinin ilgili HTTP/HTTPS sitelerinde sayfa yüklendiğinde uygulanabilmesi için.

6. Uzaktan Kod

Uzantı uzaktan çalıştırılabilir kod kullanmaz. Çalışma için gereken kodlar uzantı paketinin içindedir.

7. Sınırlamalar

Uzantı hesaplara giriş yapmaz, ödeme duvarlarını veya DRM gibi erişim kontrollerini aşmayı amaçlamaz. Chrome sistem sayfaları gibi tarayıcının kısıtladığı sayfalarda çalışmaz.
